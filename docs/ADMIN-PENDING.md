# 后台待讨论事项

当前已确定并实现：后台框架、站点设置、Core/Custom 共用设置、用户查询与权限状态管理、设置、内容、用户、账号安全操作记录、当前账号密码和会话管理、内容/分类/标签管理、普通文章发布流程、共用 API 契约及相关安全验证。

以下涉及产品规则，先不创建数据模型、占位菜单或新增依赖：

1. 首批额外内容类型及专属字段、正文格式、附件需求；通用类型注册、一个主分类和多个标签已经实现。
2. 普通用户发布和审核流程：目前管理员可直接发布、保存已发布内容会即时更新前台；举报、回收站与恢复规则待讨论。
3. 用户进入方式：开放注册、邀请或后台创建；邮箱验证、找回密码所需邮件渠道；账号删除与数据保留。
4. 更多角色：是否需要编辑、审核员、运营等角色及各自范围；目前仅普通用户与管理员。
5. Custom 设置：需要哪些可后台编辑的字段、校验与默认值；不开放任意 JSON 或脚本编辑。
6. 更多媒体与内容过滤：管理员静态图片上传和本机存储已实现；其他文件类型、普通用户上传、附件展示与审核方式仍待讨论，不先绑定第三方存储或付费审核服务。

确认相关规则后再实现对应模块；当前不提供注册、审核或邮件服务的空菜单。

正文编辑方向已确认暂时保留纯文本；后续不得把“继续”直接理解为要求安装富文本或 Markdown 编辑器。管理员已保存内容预览、组合分类/标签筛选已实现。
