# 后台验收与模拟数据验证

本轮范围为现有后台，不新增投稿、评论、审核等业务，不新增依赖，不实现前台媒体展示。生产测试数据与正式站点隔离。

## 已修复

1. 媒体维护锁与管理员权限修改锁共用了 PostgreSQL advisory lock 编号，备份会无故阻塞权限修改。改用集中维护的三个独立编号，并通过维护测试验证可以独立获取。迁移锁、管理员权限锁、媒体维护锁分别在 `packages/database/src/advisory-locks.ts` 定义。升级时需重启所有写入实例，避免新旧锁编号同时运行。
2. 媒体列表的 EXISTS 被规划器转为扫描整个 content_media 的 hashed subplan。改为标量子查询与 LIMIT 1，仍是一条 SQL，每页只对最多 31 个媒体做已有索引探测。执行计划从扫描 100,000 条引用变成 31 次最多 1 行的索引探测，无须新增媒体索引。
3. 管理员、禁用账号筛选按主键遍历普通用户。追加 010 迁移，分别为实际筛选条件建立小型部分索引，不为普通活跃用户额外创建这两类索引项。
4. 分类/标签选择器位于内容编辑表单内，搜索输入按 Enter 原本可能触发表单保存。现在阻止默认提交并执行搜索，保留中文输入法候选确认。浏览器以合法标题测试，Enter 后 submit 事件数为 0，编辑页面和输入保留。
5. 手机模拟器中导航、查询、重置和折叠选择器的触控区域偏小。仅在 coarse pointer 下扩大主要按钮和筛选控件的点击区域，保留桌面紧凑布局和黑白中性色。

## 交互验收证据

- Chromium 1440×1000 桌面与 390×844 手机视口核对内容列表、新建内容和选择器；无页面横向溢出，主导航、查询与选择器具备名称/标签。手机为浏览器模拟，并未替代真机触控或完整无障碍认证。
- 断网展开分类选择器，出现可读错误；恢复网络后通过搜索重试成功。未生成正式测试分类或内容。
- 输入未保存标题后点击同页导航，取消确认可保留编辑位置和输入；清空后恢复原状态。现有提醒覆盖关闭/刷新与同页链接，未声称完整覆盖所有浏览器历史后退场景。
- 无效 Bearer 请求返回 401；未认证页面请求返回登录界面。未撤销正式账号的真实会话。真实权限变更、会话撤销、403/409、内容发布/下架/删除、媒体引用保护和备份恢复由隔离集成测试覆盖。
- 表单错误保留可重试入口；保留版本冲突保护和已保存版本预览。浏览器导航命中既有缓存时，并非实时权限推送；所有实际数据读写继续由 Core 服务校验权限。
- Impeccable detector 对后台与 admin-ui 目录完成扫描，无额外输出；结论仍以手工核对和上述测试为准。没有据此声明通过 WCAG 或覆盖全浏览器。

## 可复现性能测试

```text
pnpm test:performance
```

命令复用临时数据库运行器，限定本地数据库及随机 `sohoin_test_` 名称，执行迁移、造数、ANALYZE、真实数据库模块调用及生产 Next HTTP 请求，最后销毁临时库。媒体仅造元数据，不读取真实文件。报告存于 `.local/performance/admin-scale-latest.json`；可用 BENCH_LABEL 区分各次运行。

模拟规模：100,000 篇内容、30,001 位用户、20,000 个媒体资源、300,000 条标签关联、100,000 条媒体关联，其中单一热门媒体有约 60,000 处引用。用户姓名与编号有较强相关性，用于暴露主键分页与前缀搜索的较差分布。

每个数据库场景先运行一次，再记录 20 次查询时长、返回体积、查询数和 EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON)。创建/更新/删除循环记录 10 次，每个完整 HTTP 接口先预热，再记录 20 次。测试为单进程、单请求、热缓存本地结果，不是生产网络、并发吞吐或容量保证。

| 场景 | 改动前 P95 | 改动后 P95 |
| --- | ---: | ---: |
| 媒体列表数据库查询 | 7.94 ms | 0.40 ms |
| 管理员筛选数据库查询 | 5.21 ms | 0.52 ms |
| 禁用用户筛选数据库查询 | 2.22 ms | 0.59 ms |
| 内容列表数据库查询 | 1.75 ms | 2.05 ms |
| 内容组合筛选数据库查询 | 2.45 ms | 2.39 ms |

完整管理员 HTTP 读取接口改动后 P95 约 16–17 ms，包含会话、权限、共享限流和 JSON 响应。创建→更新→删除完整三操作循环 P95 约 12 ms，包含媒体绑定和事务审计。小幅前后变化受本机调度/缓存影响，不解读成确定回归或收益；大幅优化同时由执行计划确认。

用户前缀查询在本组最差相关性分布下仍可能按主键扫描约 28,000 行，P95 约 5.85 ms。当前保留已有前缀索引，没有为这组模拟数据强制规划器或增加通用搜索依赖；增长后须继续观察真实分布和查询计划。热门媒体引用分页最慢样本 P95 约 3.52 ms，仍每次只返回 31 条。
