# Graphify 项目索引

Graphify 用于定位 sohoin 的文件、符号、导入和调用关系，帮助阅读 `apps/web`、`packages`、`custom` 与脚本。结果只作为源码导航线索，不替代实际实现、Core 权限边界或项目规范。

## 工具前提

接入时本机已有 `graphifyy` 0.9.38，命令名为 `graphify`；命令和忽略规则依据该安装版本的 CLI 帮助及源码。它是独立的本地 Python 工具，不加入 pnpm 依赖或锁文件。其他开发机需先自行安装相应版本并确保 `graphify` 在 PATH 中；缺少工具时命令会失败，不自动安装。

当前 Codex graphify 技能声明版本为 0.8.44，与本机工具有差异。本次未升级全局技能；项目命令以本机 0.9.38 的实际能力为准，升级后需复核。

## 生成与查询

在项目根目录手动执行：

```powershell
# 首次生成；代码变化后用同一命令更新
pnpm graphify:index

# 优先使用实际符号名、文件名或模块词汇
pnpm graphify:query "settingsService"
pnpm graphify:explain "settingsService"

# 将两端替换为图中实际存在的节点名称
pnpm graphify:path "节点 A" "节点 B"
```

索引命令调用 `graphify extract . --code-only --no-cluster --max-workers 2`：只做本地 AST 提取，限制为两个工作进程，跳过语义模型提取与聚类。生成 `graphify-out/graph.json` 及工具内部缓存，不生成完整社区分析报告或可视化。重复执行由工具处理增量变化，不默认强制覆盖。

本次仅完成接入配置，未生成首次图谱，也未执行索引或查询验证。用户执行索引成功后才可查询；如提取失败，应查看实际错误，不将部分索引视为完整关系图。

## 范围与维护

- `.graphifyignore` 排除依赖、构建产物、本地数据库与媒体、备份、环境文件、静态资产和参考观测资料；工具同时遵守 Git 忽略规则。`custom/**` 作为代码纳入，但不会因索引被改写。
- `--code-only` 不对 Markdown 产品规范、设计规范、SQL 业务含义或图片做语义分析；仍须按 AGENTS.md 直接阅读适用文档。动态调用、框架约定和工作区包解析可能不完整，缺少边不代表没有依赖。
- 查询结果需核对源文件和当前位置，尤其是在尚未更新索引的工作区中。图谱缺失或过期时可直接检索源码，不阻塞开发。
- 全部产物在 Git 忽略的 `graphify-out/` 内，仅供本地开发使用，不加入 `public`、客户端包或部署产物。
- 未启用外部模型、数据库连接、Git hooks、watch 或自动更新。索引生成和更新由用户手动执行；需要语义分析或自动化时另行明确范围。
- 本次没有安装新依赖、运行应用构建、测试、性能测量或浏览器操作。
